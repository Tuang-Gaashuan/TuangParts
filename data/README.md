data/ 目录说明
==============

本目录存放**你的元器件数据**，不入 git、随 exe 分发、不随开源仓库发布。
每个一级分类对应一个 xlsx 文件（文件名中的 `/` 自动替换为 `-`），
修改/新增分类后，子分类文件在首次存入元器件时自动创建。

目录结构:

    data/
    ├── settings.json        # 程序设置 (数据路径 / 主题 / AI 接口配置)
    ├── activity_log.jsonl   # 操作记录 (导入/取出/修改流水)
    ├── undo_log.jsonl       # 撤销历史 (最近操作可一键撤回)
    ├── backgrounds/         # 你上传的界面背景图
    ├── exports/             # 数据包导出文件 (ZIP)
    └── <分类>.xlsx          # 元器件数据表 (如 电容.xlsx、电阻.xlsx)

首次运行自动创建（打包版首次启动会复制内置示例数据）。
也可用 `python seed.py` 生成示例数据（会清空本目录，正式使用后勿跑）。

表头统一为:
    名称/型号 | 品牌 | 封装 | 数量 | 库位 | 子分类 | 规格参数 | 数据手册链接 | 备注

备份提示: 本目录即全部数据, 定期复制一份即可; 
也可用程序内的「数据包 → 导出」一键打包备份。
