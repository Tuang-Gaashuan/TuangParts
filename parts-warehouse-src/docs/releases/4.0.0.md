# Parts Warehouse 4.0.0

发布日期：2026-08-28

## 更新内容

- 工作区界面重构：侧栏导航、紧凑表格工作区、库存统计和活动摘要。
- 增加独立全库搜索，可按名称、型号、品牌、封装、库位、规格和分类检索。
- BOM 匹配和 BOM 清单管理改为独立业务入口。
- 撤回操作归入出入账本，主页摘要日志清除归入设置。
- 保留主题、背景图、背景深色强度、卡片透明度、字号和字体设置。

## 发布包

- `parts-warehouse-4.0.0.exe`：单文件便携版，首次运行在 EXE 同目录创建 `data/`。
- `parts-warehouse-4.0.0-full.zip`：目录版完整包，解压后运行 `parts-warehouse.exe`。

两种发布包均使用干净种子数据：不包含库存、BOM 清单、账本、API Key、远端同步地址、本机路径或用户背景图。

## 验证

目录版和单文件版均已实际启动，`http://127.0.0.1:5000/` 返回 `200`，并确认工作区、全库搜索和 BOM 匹配入口可被加载。
