## 1. 软件简介

元器件仓库是一款**单机本地**的电子元器件库存管理软件：

- **数据就是 Excel**：没有数据库，每个子分类一个 `.xlsx` 文件，随时可以用 WPS / Excel 打开查看、备份、迁移
- **桌面 + 浏览器双形态**：桌面版为原生窗口（无地址栏），也支持纯浏览器使用
- **AI 加持但非必须**：自然语言录入、BOM 批量解析、OCR 整理可用 AI 加速；纯规则解析完全离线可用
- **完整业务闭环**：录入 → 分类 → 检索 → 取出 → 账本 → 撤回 → 同步，一步不缺

## 2. 安装与启动

### 2.1 目录版（推荐）

解压发布包中的 `directory/` 目录，双击 `parts-warehouse.exe` 即可。

- 首次运行会在 exe 旁自动生成 `data\` 目录
- 数据永远在 `data\` 目录，重装 / 重打包不丢数据

### 2.2 单文件版

解压发布包中的 `onefile/parts-warehouse.exe`，双击即用（首次运行在 exe 旁生成 `data\`）。

> 系统要求：Windows 10/11（自带 WebView2 内核，通常已预装）。

### 2.3 源码运行

```bash
pip install -r requirements.txt
python desktop.py   # 桌面窗口版
# 或
python app.py       # 纯浏览器版 http://127.0.0.1:5000
```

### 2.4 首次使用建议

1. 打开「设置 → AI 设置」，填写 AI 接口（也可跳过，纯手动/纯规则模式可用）
2. 打开「设置 → 界面设置」，选择喜欢的主题和背景
3. 从「存入元件」开始录入第一条库存

## 4. 库存管理

### 4.1 总览页 / 库存分类

- **总览页**：分类卡片只显示有记录的分类，卡片右上角为该分类元件总数；另有近期库存与最近出入摘要
- **库存分类页**：36 个一级分类卡片（参考立创商城分类），点击进入该分类下的子分类列表
- **子分类页**：只显示有数据的子分类，点击进入元器件表格
- 空分类自动隐藏（保存空列表即删除文件）

### 4.2 表格编辑

每个子分类是一个 Excel 表格，统一表头：

```
名称/型号 | 品牌 | 封装 | 数量 | 库位 | 子分类 | 规格参数 | 数据手册链接 | 备注
```

- 点击单元格直接编辑，绿色「保存」按钮写回 Excel
- `+ 新增行` 添加空行
- 表头点击排序（阻容感按数值大小排序，如 1MΩ 排在 10kΩ 前面）
- 底部显示该分类合计数量
- 「导出」当前分类为独立 xlsx

### 4.3 低库存预警

- 数量低于阈值（默认 10）的元件自动进入补货提醒清单
- 工具类不参与提醒；单片机阈值 2（仅剩 1 个时提醒）
- 侧栏 / 总览有角标显示待补货数量

### 4.4 未分类区

- AI / OCR 解析后无法确定归属分类的元件**绝不丢弃**，自动进入「未分类」区（独立橙色卡片提醒）
- 未分类界面提供：勾选 → 一级分类下拉 + 子分类联动下拉 → 「归类所选」一键归位
- 归类后自动进入对应子分类表格，并写入账本

## 5. 存入元件

### 5.1 手动录入 / AI 填入

- **手动**：`+ 新增行` 逐行填写，或直接打开 Excel 编辑
- **AI 填入**：输入自然语言，AI 解析为结构化字段，例如：

```
100个 0805 10K ±1% 贴片电阻 富信
10片 STM32F103C8T6 LQFP48 MCU
1K@35V 铝电解 直插 20个
```

质量红线（自动执行）：

- 位号（C1、R2、U5）不会被当成型号
- 电容只把容值当名称（1uF），耐压 / 材质进规格参数（50V X7R）
- NC / DNP / 不贴装 的行自动剔除
- 相同元件自动合并数量

### 5.2 批量导入（文本 / Excel）

- 支持粘贴文本、上传 `.txt`、上传 Excel（`.xlsx` / `.xls`，兼容嘉立创等 EDA 导出的 BOM）
- 自动识别表头（前置标题 / 合计 / 日期等噪声自动跳过）
- 两条解析路径：
  - **纯规则解析**：0 请求、0 token，秒级完成（标准采购明细 / BOM 走此通道）
  - **AI 解析**：表头不明确时回退 AI，全量分批发送（40 行/批，一条不漏）
- 预览确认后提交入库，可撤回

### 5.3 OCR 拍照入库

- 摄像头拍照或选择图片（支持单张 / 批量多图）
- 本地 RapidOCR 离线识别（PP-OCRv6），不依赖网络
- 标准料袋标签（MLCC / 电阻 / 电感等）优先本地规则直通，复杂情况才回退 AI
- 每张图对应一条记录（默认一图一项），保留 `source_image` 便于核对
- 结构化结果可编辑，确认后入库

## 6. 取出元件

### 6.1 手动取出

- 分类级联下拉选择 → 勾选物料 → 每行填数量 → 确认取出
- 取出自动校验库存充足，写入账本并生成撤回快照

### 6.2 BOM 匹配取出

- 上传 BOM / 粘贴文本 → 自动匹配库存，每项给出四色状态：

| 状态 | 含义 |
| --- | --- |
| ✅ 充足 | 库存精确匹配，数量够 |
| ⚠️ 可替代 | 精确不够，相似料（同值不同封装/品牌等）可补足 |
| ⚠️ 不足 | 差 N 个 |
| ❌ 缺料 | 无任何候选，自动汇总到「需要采购」清单 |

- 型号类元件严格匹配（SS34 不会匹配成 SS36）
- 跨子分类取出为**单一事务**：一次批量取出只生成一份撤回快照、一条账本记录
- 文件导入取出支持「按生产份数」放大数量（份数控件在解析成功后出现）

## 7. BOM 匹配与 BOM 清单

BOM 匹配与 BOM 清单是两个独立业务：

### 7.1 BOM 匹配（即时）

- 临时上传 / 粘贴 BOM → 匹配库存 → 确认取出
- 匹配结果不持久化

### 7.2 BOM 清单（持久化）

```
EDA BOM 导入 → 解析 → 仓库匹配 → 确认具体仓库物料 → 保存清单
→ 取出系统选择清单 → 输入生产份数 → 实时核验库存 → 确认取出
```

- 每份清单一个独立 Excel 文件，存于 `data/BOM清单/`
- 保存的是**用户确认后的具体仓库物料**（子分类 + 行号 + 物料快照），不是下次重新模糊匹配
- 缺料行仍然保留，标记「未匹配/待补料」，不参与扣减
- 清单管理窗口：查看全部行、修改需求字段、保存、删除
- 修改需求字段不覆盖已确认的仓库绑定

- 任意界面按 `Ctrl+K`（Mac `Cmd+K`）唤起独立搜索工作区

## 9. 出入账本与撤销

### 9.1 出入账本

- 每次业务操作（录入 / 取出 / 调整）记一笔账本记录：时间、动作、操作者、原因、来源、总数量变化、明细列表
- 一条业务请求 = 一条记录（批量操作不拆碎）
- 点击整行展开 / 收起明细
- 支持按开始日期、结束日期、动作筛选

### 9.2 撤回

- 每次操作自动生成撤回快照（`data/撤回日志/`，一个 Excel = 一次操作）
- 整笔撤回：整笔回滚
- 单项撤回：明细行单独回滚（原行号列保证删行后不漂移）
- 取消撤回：已撤回的操作可再恢复
- 撤回也会写入账本（可审计）

### 9.3 清除边界

- 设置页「清除操作日志」只清主页摘要，**不会清除出入账本**
- 账本页独立「清除账本」只删账本，不影响主页摘要
- 仅「清空全部数据」删除两类记录（同时保留设置）

## 10. 品牌库

- 从现有库存 Excel 的「品牌」列实时聚合出采购视图
- 同品牌多写法自动合并（FOJAN / FOJAN(富捷) / 富捷 → 同一组）
- 品牌卡片显示：业务描述、种类数、总件数、覆盖分类、型号示例
- 支持：品牌明细查看、汇总 Excel 导出、生成 `data/品牌库.xlsx` 档案
- 未填品牌的条目不生造品牌，只统计数量并提示

## 11. 线上同步（Git / Gitee）

### 11.1 两种平台

- `sync_provider = gitee`：使用 Gitee 仓库
- `sync_provider = git`：使用 Git / GitHub 仓库
- 平台与远端地址严格匹配，防止「界面显示 Gitee、实际连 GitHub」的错配

### 11.2 同步模式

- **浏览不阻塞**：查看库存、分类、账本不访问网络
- **写入前保护**：真正改变库存的确认动作前检查同步状态
- **事件粒度**：一条账本记录 = 一条事件文件（`events/年/月/日/<event_id>.json`），明细全部放 `items[]`
- **提交本机账本**：一键把 pending 账本记录提交到线上，可重复提交（生成新事件 ID）
- 线上事件读回账本（origin=remote，只读展示，不自动改库存）

### 11.3 配置要求

- 设置页填写：远端仓库地址、本地目录、分支、用户名
- 凭据使用系统 Git Credential Manager / SSH，不写入设置文件

## 12. 数据包（备份 / 迁移 / 分享）

- **导出**：全部分类 + 未分类 → 单个 ZIP（含 manifest），存 `data/exports/`
- **导入**：合并模式，同名子分类按四键规则合并数量，导入前自动备份
- 导出自动排除：运行时目录、撤回日志、缓存、设置、旧导出包
- 导入自动跳过：撤回日志快照文件（undo-*.xlsx），避免快照被误当库存
- **换电脑**：导出 → 拷贝 ZIP → 新电脑导入
- **分享模板**：导出后清空数据即可

## 15. 设置详解

设置入口：侧栏 ⚙（或页面内「同步设置」等按钮）。设置弹窗共 5 个页签：

### 15.1 📁 数据路径

## 16. 命令行工具 rk（拍照入库）

桌面版可选 CLI，适合有摄像头的台式机快速录入料袋：

```bash
./rk                     # 打开摄像头拍照入库（空格=拍照 回车=结束 Backspace=撤回）
./rk a.jpg b.jpg         # 指定图片文件入库
./rk -d ./袋料照片        # 处理目录下所有图片
./rk --no-ai             # 纯规则解析，无需 AI/key/网络
./rk -y                  # 跳过逐条确认直接入库
./rk --device 0          # 摄像头编号（默认 1）
```

流程：拍照/图片 → OCR 识别 → AI 按料袋模板整理 → 解析分类 → 逐条确认 → 入库。复用主程序全部质量红线（位号防护 / NC 剔除 / 电容规范化 / 重复合并 / 未分类区 / 可撤销）。

## 17. 常见问题（FAQ）

**Q: 数据会不会丢？**
A: 所有数据都是 `data/` 里的 xlsx，复制目录即备份；每次数据包导入前自动备份；每次操作可撤回。

**Q: 不想用 AI 行不行？**
A: 行。手动录入、纯规则批量导入、rk `--no-ai` 都不需要 AI。

**Q: 可以用哪些 AI？**
A: 任何 OpenAI 兼容接口：DeepSeek、智谱 GLM、硅基流动、通义、Ollama 本地模型等，设置里填 base_url / key / model 即可。

**Q: 换电脑怎么迁移？**
A: 「数据包导出」→ 拷贝 ZIP → 新电脑「数据包导入」；或直接复制整个 `data/` 目录。

**Q: 为什么有些元件进了未分类？**
A: AI/OCR 无法确认归属时会进未分类，可在未分类页手动归类；批量导入无法识别的行也会进未分类，绝不丢失。

**Q: 导入旧版导出的数据包会不会出问题？**
A: 不会。4.0 导入会自动跳过撤回日志快照、按 ZIP 目录+行内子分类恢复分类、旧命名自动归一化，导入前自动备份。

**Q: 怎么和其他人协作？**
A: 使用「线上同步」（Git/Gitee 增量事件）或共享 data 目录；多人实时扣减仍建议以本机账本为准。

**Q: WebView2 是什么？为什么需要？**
A: 桌面版窗口基于 Edge 内核（WebView2）渲染，Windows 10/11 通常已预装，无需额外安装。
