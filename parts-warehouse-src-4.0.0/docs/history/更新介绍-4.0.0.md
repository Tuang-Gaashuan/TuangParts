## 一、本次更新核心

### 1. 全新 Codex 风格工作区界面
- 整体重构为深色中性、高信息密度的工作区布局：固定左侧导航、细边框、低圆角、无渐变
- 侧栏支持展开 / 收起、拖拽调宽，状态自动记忆（刷新后保留）
- 移动端窄屏自动切换为抽屉式导航
- 主页改为信息工作区：分类总览 + 近期库存 + 最近操作，真实数据渲染，不再是大色块卡片墙
- 保留全部业务能力：库存、分类、BOM 匹配 / BOM 清单、账本、撤回、线上同步、设置、自定义主题、背景图、背景亮度 / 卡片透明度

### 2. 真正的全库搜索（Ctrl+K）
- 顶部 / 侧栏搜索入口直接打开独立搜索工作区，无需先进入某个库存分类
- 全库真实数据检索：名称 / 型号、品牌、封装、库位、规格、一级分类、子分类
- 点击结果直接进入对应子分类表格
- 支持 `Ctrl+K` / `Cmd+K` 快捷键唤起

### 3. 数据包导入分类修复（重要修复）
**修复背景**：之前从旧版导出的数据包再导入时，部分元件被错误地归入「未分类」区，界面出现几百条未分类，看起来像分类丢失。

**修复内容**：
- 导入时优先按 ZIP 数据包内的一级分类目录 + 文件名恢复标准分类
- 目录 / 文件名与当前分类体系不一致时，逐行读取 Excel 内的「子分类」字段恢复，而不是整表丢进未分类
- 只有确实没有合法分类信息的行才进入「未分类」区，且绝不静默丢弃
- 本次已对受影响数据执行一次恢复迁移：**764 条未分类元件全部按原分类归位，未分类区归零**，无任何数据丢失（迁移前完整备份保留在 `backups/`）

### 4. 深色主题与背景透明度修复
- 修复 WebView2 首帧 / 变量回退导致的「背景深色、侧栏 / 窗口雪白」问题
- 无背景图时使用自包含实体深色，杜绝白块
- 启用背景图后，卡片透明度滑块真实作用于侧栏、面板、表格、账本、弹窗

### 5. 新图标
- 应用程序图标（EXE 图标、窗口标题栏图标、浏览器标签 favicon）已整体更换为新图标

## 三、安装与使用

### 目录版（推荐）
解压 `parts-warehouse-4.0.0-windows.zip` 中 `directory/` 目录，双击 `parts-warehouse.exe`。

### 单文件版
`parts-warehouse-4.0.0-windows.zip` 中 `onefile/parts-warehouse.exe`，双击即用（首次运行在 exe 旁生成 `data\`）。

- 数据永远在程序旁的 `data\` 目录，重装 / 重打包不丢数据
- 依赖 Windows 10/11 自带 WebView2（通常已预装）

### 源码运行
```bash
pip install -r requirements.txt
python desktop.py   # 桌面窗口版
# 或
python app.py       # 纯浏览器版 http://127.0.0.1:5000
```
